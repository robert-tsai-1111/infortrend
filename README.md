# infortrend repo


## aoi-html

Static html page(s) to demostrate IEC VM HA feature

VM spec:
Windows Server 2019
-Static Ip address
-Enable Remote Desktop
-Enable Inbound 8080
Install Simple Web Server
- Download index.html to C:\Demo
- Adding a service link to C:\Demo

### Demo

Open http://<vm_ip>:8080
