
### Installation Flow

To install and configure your KS systems for the first time, please complete the following tasks in the specified order.

1.Plan the cluster topology and network IP assignment.

2.Prepare drives and installation tools.

3.Unpack one node and check its package contents.

4.Install hardware components for the node.

5.Power on the node and check its system status.

6.Repeat steps 2 to 5 above for the other nodes one by one.

7.Add external storage.

8.Connect network cables for the nodes and external storage and check the network status.

9.Deploy the cluster via the Cluster Deployment Wizard.

10.Access the application management interface.

11.Ready to use (workload management)

Workload Management refers to the daily operational and administrative tasks that users perform via servers, primarily encompassing the following categories of activities:

* Application Chart Management: add new appliaciton chart repositories; deploy new application charts; scale-up memory size to database charts; scale-up vGPU to AI apps, ... ...
* Container Management: deploy container registry (Harbor); deploy new application charts; scale-out containers; ...
* Virtual Machine Management: provision new Windows VM; migrate VMware VMDK VMs; stop legacy VMs; scale-up disk size; ...
* HPC Job Management: launch WRX computing jobs; ...
