
### Prepare Cluster and Network Components


Prepare the following components based on your cluster topology and network combination.

* RJ45 cables (management and IPMI networks)
* LC or DAC cables (host and storage networks)
* Transceivers
* Management Server
* HBA (must be purchase from Infortrend)
* GPU (depending on the model)

> **⚠️ Important!**
>
> To make sure you have the compatible components, refer to the Compatibility Guide (QVL) on Infortrend’s website. Go to Support > Technical Support, find your model, and then go to Downloads.
