# KS Technical Training Program

## From Infrastructure Foundations to AI Workload Management
## Build Your Expertise Across the Server & AI Ecosystem

To help customers accelerate their technical adoption and maximize the value of the KS platform, we offer a structured technical training program covering the server, GPU, software, Kubernetes, virtualization, storage, cluster management, and workload operations.

The program is designed to provide a progressive learning journey—from foundational concepts to hands-on platform administration and troubleshooting.

## Learning Modules

[Learning Module List](./learning_modules.md)

## What You Will Gain

Through this training program, participants will develop a comprehensive understanding of the KS platform and gain the knowledge required to:

- Understand the overall server and AI infrastructure ecosystem

- Navigate the KS hardware and software architecture

- Deploy and manage KS clusters

- Build foundational knowledge of Kubernetes, containers, virtualization, and container storage

- Manage servers through BMC and cluster administration

- Perform server operations and troubleshooting

- Manage containerized applications and workloads

- Understand VM, KubeVirt, GPU Passthrough, and VM HA capabilities

- Leverage the Enterprise Application Marketplace for application deployment

## Recommended Learning Journey
