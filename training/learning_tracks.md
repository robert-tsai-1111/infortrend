### 1. KS Foundation

Build a strong foundation in the KS platform, its industry positioning, and the server and AI infrastructure ecosystem.

- **KS-01 — KS Overview**
- **KS-02 — KS Mission, Industry & Advantages**
- **KS-05 — KS Hardware Roadmap**
- **KS-06 — KS Software Roadmap**

### 2. KS Architecture & Deployment

Understand the KS hardware and software architecture and learn the fundamentals of KS cluster deployment.

- **KS-02 — Hardware Introduction**
- **KS-03 — Software Introduction**
- **KS-04 — Installation**
- **KS-35 — Get Started with BMC**

### 3. Cloud Infrastructure & Platform Management

Develop practical knowledge of Kubernetes, virtualization, container storage, cluster administration, and server operations.

- **KS-31 — Get Started with Kubernetes (EonKube)**
- **KS-32 — Get Started with Virtualization (EonKube)**
- **KS-33 — Get Started with Container Storage (EonOne)**
- **KS-05 — Cluster Administration**
- **KS-51 — Server Operation & Troubleshooting**

### 4. Workload & Application Management

Learn how to manage containerized applications, virtual machines, GPU resources, high availability, and enterprise applications.

- **KS-06 — Container Application Management**
- **KS-07 — Virtual Machine Management**
- **KS-71 — VM HA Service**
- **KS-08 — Enterprise Application Marketplace**

## Recommended Learning Journey

**Foundation → Architecture → Deployment → Platform Management → Workload & Application Management**

This structured learning journey enables participants to progressively build the knowledge and skills required to understand, deploy, operate, and manage KS infrastructure.

## Target Audience

This training program is suitable for:

- IT Administrators
- System Engineers
- Infrastructure Engineers
- DevOps Engineers
- Cloud Platform Engineers
- AI Infrastructure Teams
- Technical Support and Operations Teams

## Training Outcomes

After completing the relevant training modules, participants will be able to:

- Understand the overall server and AI infrastructure ecosystem
- Explain the KS platform architecture and key capabilities
- Understand KS hardware, GPU, and integrated software components
- Deploy and manage KS clusters
- Apply Kubernetes, virtualization, and container storage concepts
- Perform server and cluster administration
- Troubleshoot common server and infrastructure issues
- Manage containerized applications and workloads
- Understand VM, KubeVirt, GPU Passthrough, and VM high-availability concepts
- Utilize the Enterprise Application Marketplace
